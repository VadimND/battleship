# Battleship with Websockets and NodeJS
>
> Battleship - game for play with partner or in single mode.
> Main rule is to destroy fleet of enemy.

## Installation

1. `git clone https://github.com/VadimND/battleship.git`
2. `cd battleship`
3. `git checkout dev`
4. `npm install`

## Usage

**Development**

`npm run start:dev`

* App served @ `http://localhost:8181` with nodemon

**Production**

`npm run start`

* App served @ `http://localhost:8181` without nodemon

---

**All commands**

Command | Description
--- | ---
`npm run start:dev` | App served @ `http://localhost:8181` with watch option
`npm run start` | App served @ `http://localhost:8181`

**Note**: replace `npm` with `yarn` in `package.json` if you use yarn.
